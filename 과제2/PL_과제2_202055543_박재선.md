# BNF 설계 연습문제

- 202055543
- 박재선

## 1. BNF
> 4번의 답을 위하여 괄호를 처리하는 부분은 제외 
```bnf
<expr> -> <or_expr> 
<or_expr> -> <or_expr> OR <and_expr> | <and_expr> 
<and_expr> -> <and_expr> AND <not_expr> | <not_expr> 
<not_expr> -> NOT <not_expr> | <comp> 
<comp> -> <identifier> > <literal> | <identifier> = <literal> 
<identifier> -> age | name | city
<literal> -> 20 | 'A' | 'Seoul'
```
## 2. 파싱 방식
- 문제에서 제시한 논리 연산의 우선순위에 따르면 AND가 OR보다 높은 우선순위를 가진다.
- 그에 따라 작성한 1번의 BNF에 의해 \<and_expr\>이 \<or_expr\> 파싱 트리에서 더 깊이 위치하게 된다.
- 따라서, (age > 20 AND name = 'A') OR city = 'Seoul' 로 파싱되어야 한다.

## 3. 파싱 설명
1. \<comp\> 를 정의하는 규칙에 따라 age와 20은 각각 \<identifier\>와 \<literal\>로 파싱된다.
2. 이후 \<not_expr> 규칙에 따라 \<comp\>가 \<not_expr\>로 파싱된다. 
3. \<not_expr\> 에 따라 단말 노드 NOT과 함께 <not_expr> 로 재귀적으로 \<not_expr\> 로 두 번 파싱된다. 
4. 이후 계속 이어져 \<expr\> 로 파싱된다. 

## 4. 괄호 처리
> 1번의 답을 수정하여 괄호를 처리하는 부분 추가 
```bnf
<expr> -> <or_expr>
<or_expr> -> <or_expr> OR <and_expr> | <and_expr>
<and_expr> -> <and_expr> AND <not_expr> | <not_expr> 
<not_expr> -> NOT <not_expr> | <exp>
<exp> -> (<expr>) | <comp> 
<comp> -> <identifier> > <literal> | <identifier> = <literal> 
<identifier> -> age | name | city
<literal> -> 20 | 'A' | 'Seoul'
```

## 5. (Option) EBNF
```bnf
<expr> -> <or_expr>
<or_expr> -> <and_expr> {OR <and_expr>}
<and_expr> -> <not_expr> {AND <not_expr>} 
<not_expr> -> {NOT} <comp> 
<comp> -> <identifier> (> | =) <literal>
<identifier> -> age | name | city
<literal> -> 20 | 'A' | 'Seoul'
```
